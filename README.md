# Control-Horario-BytesPC
 Planificador de turnos local para PY# Bytes PC - Control Horario

Software de escritorio (Windows) para la planificación de turnos y cuadrantes de personal, desarrollado por **Bytes PC**.

## 🚀 Características
- **100% Local y Offline**: No requiere internet ni servidores externos. Los datos se guardan de forma segura en el ordenador.
- **Generación automática**: Crea los turnos de todo el mes basándose en el horario semanal de cada empleado.
- **Gestión de ausencias**: Control de vacaciones, descansos y festivos.
- **Turnos partidos**: Soporte para jornadas de mañana y tarde.
- **Arrastrar y soltar**: Modifica los turnos de forma visual e intuitiva.
- **Exportación**: Genera cuadrantes en PDF (con tu logo) y exporta a Excel (CSV).
- **Seguridad**: Base de datos protegida en el `AppData` del usuario y acceso mediante contraseña.

## 🛠️ Tecnologías utilizadas
- **Backend**: PHP 8 + SQLite (PDO)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Empaquetado**: PHP Desktop (Chromium) + Inno Setup

## 📦 Instalación (Desarrolladores)
1. Descargar PHP Desktop.
2. Copiar los archivos de la carpeta `www` en el directorio correspondiente.
3. Ejecutar `phpdesktop-chrome.exe`.
